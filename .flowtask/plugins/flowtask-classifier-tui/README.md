# FlowTask Classifier TUI Plugin

> **Deprecated / Deprecated:** This plugin is deprecated and is not installed by default. Its source is preserved as the visual indicator for the deprecated classifier unit and can only be reactivated together with `flowtask-classifier-hook`; enable both manifest entries before running `flowtask update`.

Este plugin proporciona el indicador visual del clasificador de FlowTask. El código fuente se conserva, pero el componente no se instala por defecto.
