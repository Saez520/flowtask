# Output Verbosity

Verbosity levels for different output types. Match the level to the content.

---

## By Output Type

| Output Type | Verbosity | Style |
|-------------|-----------|-------|
| Interview turns | Concise | 3-6 sentences + 1-3 focused questions |
| Research summaries | Balanced | ≤5 bullets with concrete findings |
| Plan generation | Detailed | Full structured markdown per template |
| Status updates | Concise | 1-2 sentences with concrete outcomes |
| User questions | Balanced | 2-4 options + recommended default |
| Verdict (Momus) | Concise | Prose, 1-2 sentences |

---

## Blacklist

**NEVER open with**:
- "Great question!"
- "That's a great idea!"
- "You're right to call that out"
- "Done —"
- "Got it"

**NEVER end with**:
- "Let me know if you have questions"
- "When you're ready, say X"

**ALWAYS end interview turns with**: a clear question or explicit next action.

---

## By Level

### Concise
- Direct answer or single point
- No filler, no narration of tool calls
- Action-oriented

### Balanced
- Brief context + main content
- 2-4 supporting points or options
- Recommended option first

### Detailed
- Full structured format
- All sections present
- Complete references and criteria
