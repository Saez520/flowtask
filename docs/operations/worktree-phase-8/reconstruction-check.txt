6. Normalisation of the published matrix
----------------------------------------

The matrix writes the isolated repositories it creates under a temporary
directory, and that root is spelled in three ways: the resolved real path of
the temporary directory, the path of the temporary directory itself, and its
lower-cased spelling, which the test embeds in the work identifier. The
published file replaces those three spellings with the token <matrix-root>:

  <resolved-tmpdir>/ft-consumer-matrix-<random>   ->  <matrix-root>
  <tmpdir>/ft-consumer-matrix-<random>            ->  <matrix-root>
  <lower-cased-tmpdir>/ft-consumer-matrix-<random> ->  <matrix-root>

After the substitution the file contains no absolute temporary path, and every
cell keeps its expected code, its observed code, its messages, its barrier
markers and the state observed before and after the call.
